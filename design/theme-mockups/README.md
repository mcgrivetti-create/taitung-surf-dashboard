# Theme mock-ups (saved 2026-10-14)

Seven phone-size design directions for the dashboard, kept in case the site
switches look later. Live canvas (private): https://claude.ai/artifact/TuduKcESfDnmUTrAUnVZpx

These are Design-canvas artboards (`.dc.html`), not site pages: open them on the
canvas, or use them as the spec when restyling `css/style.css`.

| File | Theme | Fonts | Look |
|---|---|---|---|
| `project/Main.dc.html` | 1 · Lantern | Noto Serif TC + Noto Sans TC | Taiwan temple / night market: ink black, vermilion, gold, jade; bilingual; seal-stamp ratings |
| `project/Neon.dc.html` | 2 · Night Session | Space Grotesk + JetBrains Mono | Neon, matches the surf map: cyan / magenta glow |
| `project/Retro.dc.html` | 3 · Endless Summer | Shrikhand + Rubik | 70s surf poster: sunset stripes, sticker cards |
| `project/Chart.dc.html` | 4 · Tide Chart | Archivo + IBM Plex Mono | Swiss nautical: hairlines, huge numerals, signal orange |
| `project/Neon80s.dc.html` | 5 · Outrun | Monoton + Audiowide + Rajdhani | 80s: striped sun, pink grid, palms |
| `project/Mist.dc.html` | 6 · Mountain Mist | Shippori Mincho B1 + Zen Kaku Gothic New | Misty layered peaks, bamboo accents (chosen 2026-10-14) |
| `project/Amis.dc.html` | 7 · Coast Weave | Syne + Outfit | Amis-inspired: black ground, Taitung Amis colours, woven band, shell beads, tassels |

`project/canvas.json` is the canvas layout (one page per theme).
